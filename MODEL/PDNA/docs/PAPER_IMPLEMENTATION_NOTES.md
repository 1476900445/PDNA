# 论文实现边界

1. OCEAN 在论文中既称“五维人格”，又在式(6)后写“softmax 后取最大类别”。
   当前实现按五类概率分布处理，并保留完整后验供 EXPO 使用。
2. 式(4)-(5)中的 W 未给维度。实现采用 W_CI: 5×23、W_II: 23×23、
   W_IS: 23×10、W_SS: 10×10。
3. 表 4 给出 EXPO 状态维度 40/45，但式(8)/(10)拼接 one-hot 后维度更高。
   实现先按公式完整拼接，再用可训练投影得到表 4 维度。
4. 论文未给文本底座和 tokenizer。SeTformer 接受已经得到的术语向量、
   交互特征和历史 token embedding，以免错误绑定任意预训练模型。
5. 检查纠正模块保留 DeepSeek-14B 的评分器/修订器协议和论文损失。
   由于权重与私有微调集不在 PDF 中，不下载或伪造模型。
